# Laboratorio Matemático

Repositorio base para desarrollar y publicar juegos y simuladores interactivos de Matemática.

## Juegos disponibles

1. Operatoria combinada
2. Prismas y redes
3. Despeja la X
4. Sistemas de ecuaciones

## Sitio principal

El archivo `index.html` contiene el laboratorio con sus cuatro juegos y es la página de inicio del sitio. Se mantiene una copia en `laboratorio-matematico.html` por compatibilidad con enlaces compartidos anteriormente.

Los juegos funcionan directamente en el navegador, sin pedir nombres ni enviar respuestas a un servidor.
